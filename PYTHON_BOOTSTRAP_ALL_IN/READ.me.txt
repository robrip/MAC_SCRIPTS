# 🐍 **PYTHON_BOOTSTRAP_ALL_IN**  
### **Full Python Environment Bootstrap for macOS (Homebrew + pipx + pyenv + Poetry + venv)**

**PYTHON_BOOTSTRAP_ALL_IN** is a one‑shot macOS bootstrap script that configures a complete, modern Python development environment using Homebrew, pipx, pyenv, virtualenv, and Poetry.  

It is designed for developers who want a fully‑functional Python stack with zero manual setup — everything from PATH fixes to package managers to environment tooling is handled automatically.

This script is part of the **CLAUDEWAD** neon‑diagnostic tooling suite.

---

## ⚡ **What This Script Does**

This script performs **eight major setup steps**:

### 1. 🛣 Adds Homebrew to your PATH  
Appends the following to `~/.zshrc`:

> `export PATH="/opt/homebrew/bin:/opt/homebrew/sbin:$PATH"`  


Ensures Homebrew binaries are always discoverable.

---

### 2. 🔗 Adds Python unversioned symlinks  
Adds Homebrew’s Python shims to PATH:

> `export PATH="/opt/homebrew/opt/python@3.14/libexec/bin:$PATH"`  


This ensures `python`, `python3`, `pip`, and `pip3` resolve to the correct interpreter.

---

### 3. 📦 Installs pipx  
Runs:

- `brew install pipx`
- `pipx ensurepath`

Provides isolated CLI tool installs (e.g., `black`, `ruff`, `httpie`).

---

### 4. 🧬 Installs pyenv  
Installs pyenv via Homebrew and configures:

> `export PYENV_ROOT="$HOME/.pyenv"`  
> `export PATH="$PYENV_ROOT/bin:$PATH"`  
> `eval "$(pyenv init -)"`  


Allows multiple Python versions to coexist cleanly.

---

### 5. 📁 Installs virtualenv  
Runs:

- `pip3 install virtualenv`

Provides classic virtual environment creation.

---

### 6. 🎼 Installs Poetry  
Runs the official installer:

> `curl -sSL https://install.python-poetry.org | python3 -`  


Adds Poetry’s binary directory to PATH:

> `export PATH="$HOME/.local/bin:$PATH"`  


---

### 7. 🔄 Reloads your shell  
Executes:

- `source ~/.zshrc`

This applies all PATH changes immediately.

---

### 8. 🧪 Creates a test virtual environment  
Creates:

- `~/python-env-test/venv`

And prints activation instructions:

> `source ~/python-env-test/venv/bin/activate`  


---

## 🚨 **Important Notes Before Running**

### ✔ This script **modifies your `~/.zshrc`**  
It appends multiple PATH exports and pyenv initialization lines.

### ✔ This script **installs software via Homebrew**  
pipx, pyenv, and dependencies.

### ✔ This script **creates directories in your home folder**  
`~/python-env-test`

### ✔ This script is intended for **macOS + Zsh**  
It assumes:

- Homebrew is installed at `/opt/homebrew`
- Your shell is Zsh (default on macOS)
